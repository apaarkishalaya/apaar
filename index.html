আপনার সন্তানের তথ্য দিয়ে APAAR ID দেখুন।

কীভাবে APAAR ID পাবেন ও সংরক্ষণ করবেন
  1. উপরের ঘরে সন্তানের পুরো নাম ইংরেজিতে লিখুন (স্কুলের রেকর্ড অনুযায়ী, যেমন: AARSHI MAJUMDAR)।
  2. তার নিচে জন্ম তারিখ বেছে নিন।
  3. "APAAR ID দেখুন" বোতামে চাপ দিন। সবুজ বক্সে ১২ সংখ্যার APAAR ID দেখা যাবে।
  4. "Download ID" বোতামে চাপ দিলে ID-টি একটি ছবি হিসেবে ফোনে সেভ হয়ে যাবে। অথবা "Copy ID" চেপে নম্বরটি কপি করে রাখুন।
  5. "পাওয়া যায়নি" দেখালে নামের বানান ও জন্ম তারিখ আবার মিলিয়ে দেখুন। "এখনও তৈরি হয়নি" দেখালে ১-২ দিন পরে আবার চেষ্টা করুন। সমস্যা থাকলে স্কুলে যোগাযোগ করুন।
